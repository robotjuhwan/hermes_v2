# Jue LLM Wiki Conversion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert HERMES/Jue's growing RAG and memory context into a scoped LLM Wiki layer that compiles research, block ledgers, and reflections into compact, auditable Markdown knowledge used by KIS and Binance managers.

**Architecture:** Keep existing SQLite and Chroma/RAG stores as source-of-truth provenance. Add a `JueWikiService` that reads those sources, writes scoped Markdown pages plus a small SQLite provenance index, and exposes compact context packs to `InvestmentMemoryService.context_pack()`, KIS manager, Binance manager, market judge, and UI/API routes. The first production cut makes the wiki a primary context source while preserving raw RAG and ledger fallback for evidence checks.

**Tech Stack:** Python 3.10+, FastAPI routers under `src/tradecraft/api`, SQLite via stdlib `sqlite3`, Markdown files under `.runtime/jue_wiki`, existing Codex native runtime, existing pytest suite, static frontend in `src/tradecraft/web/static`.

---

## Scope And Non-Goals

This plan builds an LLM Wiki layer for Jue. It does not delete the current RAG store, block ledgers, or investment memory DB. It does not change exchange execution rules, safety gates, or live order routing. It does not fine-tune a model. It does not make the wiki a source of truth for fills, orders, PnL, or account balances.

The wiki is a compiled interpretation layer. Source-of-truth remains:

- Reports/RAG: `.runtime/rag_chroma`, Naver reports DB, ETF research DB, crypto research DB.
- Trading ledger: `.runtime/kis_blocks.db`, `.runtime/binance_blocks.db`.
- Learning/provenance: `.runtime/investment_memory.db`, live performance/edge/validation DBs.

## Page Schema

Every page must start with frontmatter:

```markdown
---
scope: kis
page_type: symbol
title: 삼성전자
symbols: ["005930"]
confidence: 0.72
freshness: fresh
last_reviewed_at: "2026-06-28T09:00:00+09:00"
source_count: 14
status: active
---
```

Every page must use these sections:

```markdown
# Title

## Current Stance

## Durable Facts

## Evidence Links

## Trading History

## Lessons

## Contradictions

## Open Questions

## Next Context Pack Summary
```

Page type section rules:

- `symbol`: must include `Trading History`, `Lessons`, `Next Context Pack Summary`.
- `playbook`: must include `Entry Conditions`, `Exit Conditions`, `Failure Modes`, `Performance Evidence`.
- `regime`: must include `Current Markers`, `Risk Posture`, `Useful Playbooks`, `Invalidated Playbooks`.
- `lesson`: must include `Observed Pattern`, `Evidence`, `Behavioral Change`.
- `core`: must include `Principle`, `Scope`, `Where It Applies`, `Where It Does Not Apply`.

```python
from __future__ import annotations

from dataclasses import dataclass
from typing import Any, Protocol

from fastapi import APIRouter
from pydantic import BaseModel


class WikiServiceProtocol(Protocol):
    def status(self) -> dict[str, Any]: ...

    def context_pack(
        self,
        *,
        target_scope: str = "",
        symbols: list[str] | None = None,
        page_types: list[str] | None = None,
        max_chars: int | None = None,
    ) -> dict[str, Any]: ...

    def read_page(self, page_id: str) -> dict[str, Any]: ...

    def rebuild(self, *, scope: str = "", force: bool = False) -> dict[str, Any]: ...

    def lint(self, *, scope: str = "") -> dict[str, Any]: ...


@dataclass(frozen=True)
class WikiRouteDeps:
    service: WikiServiceProtocol


class WikiRebuildRequest(BaseModel):
    scope: str = ""
    force: bool = False


class WikiLintRequest(BaseModel):
    scope: str = ""


def build_wiki_router(deps: WikiRouteDeps) -> APIRouter:
    router = APIRouter()

    @router.get("/api/wiki/status")
    async def wiki_status() -> dict[str, Any]:
        return deps.service.status()

    @router.get("/api/wiki/context")
    async def wiki_context(
        scope: str = "",
        symbol: str = "",
        page_type: str = "",
        max_chars: int | None = None,
    ) -> dict[str, Any]:
        symbols = [symbol.strip()] if symbol.strip() else []
        page_types = [page_type.strip()] if page_type.strip() else []
        return deps.service.context_pack(
            target_scope=scope,
            symbols=symbols,
            page_types=page_types,
            max_chars=max_chars,
        )

    @router.get("/api/wiki/pages/{page_id}")
    async def wiki_page(page_id: str) -> dict[str, Any]:
        return deps.service.read_page(page_id)

    @router.post("/api/wiki/rebuild")
    async def wiki_rebuild(payload: WikiRebuildRequest) -> dict[str, Any]:
        return deps.service.rebuild(scope=payload.scope, force=payload.force)

    @router.post("/api/wiki/lint")
    async def wiki_lint(payload: WikiLintRequest) -> dict[str, Any]:
        return deps.service.lint(scope=payload.scope)

    return router
```

```python
from __future__ import annotations

import hashlib
import json
import re
import sqlite3
from dataclasses import dataclass
from datetime import datetime, timezone
from pathlib import Path
from typing import Any


WIKI_SECTION_ORDER = [
    "Current Stance",
    "Durable Facts",
    "Evidence Links",
    "Trading History",
    "Lessons",
    "Contradictions",
    "Open Questions",
    "Next Context Pack Summary",
]


@dataclass(frozen=True)
class JueWikiConfig:
    root_path: Path
    db_path: Path
    context_max_chars: int = 24000
    page_max_chars: int = 12000
    context_page_limit: int = 8


def _utc_now_iso() -> str:
    return datetime.now(timezone.utc).isoformat()


def _clean_key(raw: str) -> str:
    value = re.sub(r"[^A-Za-z0-9가-힣_.-]+", "_", str(raw).strip())
    value = value.strip("._-")
    return value or "unknown"


def _json_dumps(value: Any) -> str:
    return json.dumps(value, ensure_ascii=False, sort_keys=True)


def _hash_text(value: str) -> str:
    return hashlib.sha256(value.encode("utf-8")).hexdigest()


class JueWikiService:
    def __init__(self, config: JueWikiConfig) -> None:
        self.config = config

    def initialize(self) -> dict[str, Any]:
        self.config.root_path.mkdir(parents=True, exist_ok=True)
        self.config.db_path.parent.mkdir(parents=True, exist_ok=True)
        self._init_db()
        self._write_static_file("AGENTS.md", self._agents_md())
        self._write_static_file("schema.md", self._schema_md())
        self._write_static_file("index.md", "# Jue Wiki Index\n\nNo compiled pages yet.\n")
        self._write_static_file("log.md", "# Jue Wiki Log\n\n")
        self._write_static_file("freshness.md", "# Jue Wiki Freshness\n\n")
        self._write_static_file("contradictions.md", "# Jue Wiki Contradictions\n\n")
        for scope in ("core", "kis", "binance"):
            (self.config.root_path / scope).mkdir(parents=True, exist_ok=True)
        return {"status": "ok", "root_path": str(self.config.root_path), "db_path": str(self.config.db_path)}

    def _connect(self) -> sqlite3.Connection:
        conn = sqlite3.connect(self.config.db_path)
        conn.row_factory = sqlite3.Row
        return conn

    def _init_db(self) -> None:
        with self._connect() as conn:
            conn.executescript(
                """
```

```python
        return filtered

    def _group_rows_by_symbol(self, *, path: Path, query: str) -> dict[str, list[dict[str, Any]]]:
        grouped: dict[str, list[dict[str, Any]]] = {}
        with sqlite3.connect(path) as conn:

            for row in conn.execute(query).fetchall():
                payload = {key: row[key] for key in row.keys()}
                symbol = str(payload.get("symbol") or "").strip().upper()
                if symbol:
                    grouped.setdefault(symbol, []).append(payload)
        return grouped
```

```python
    def context_pack(
        self,
        *,
        target_scope: str = "",
        symbols: list[str] | None = None,
        page_types: list[str] | None = None,
        max_chars: int | None = None,
    ) -> dict[str, Any]:
        self.initialize()
        budget = max_chars or self.config.context_max_chars
        clean_scope = str(target_scope or "").strip().lower()
        symbol_set = {str(symbol).strip().upper() for symbol in symbols or [] if str(symbol).strip()}
        page_type_set = {str(page_type).strip().lower() for page_type in page_types or [] if str(page_type).strip()}
        rows = self._select_context_pages(
            target_scope=clean_scope,
            symbols=symbol_set,
            page_types=page_type_set,
            limit=self.config.context_page_limit,
        )
        pages: list[dict[str, Any]] = []
        chunks: list[str] = []
        used = 0
        for row in rows:
            page_id = str(row["page_id"])
            content = self._extract_context_summary(page_id)
            if not content:
                continue
            next_len = len(content) + 2
            if used + next_len > budget:
                remaining = max(budget - used - 80, 0)
                if remaining <= 0:
                    break
                content = content[:remaining].rstrip() + "\n- Context truncated by budget."
                next_len = len(content) + 2
            chunks.append(content)
            pages.append(
                {
                    "page_id": page_id,
                    "scope": row["scope"],
                    "page_type": row["page_type"],
                    "title": row["title"],
                    "confidence": row["confidence"],
                    "freshness": row["freshness"],
                }
            )
            used += next_len
            if used >= budget:
                break
        content = "\n\n".join(chunks)
        return {
            "status": "ok",
            "target_scope": clean_scope or "all",
            "symbols": sorted(symbol_set),
            "pages": pages,
            "content": content,
            "char_count": len(content),
            "budget": budget,
        }

    def _select_context_pages(
        self,
        *,
        target_scope: str,
        symbols: set[str],
        page_types: set[str],
        limit: int,
    ) -> list[sqlite3.Row]:
        clauses = ["status = 'active'"]
        params: list[Any] = []
        if target_scope:
            clauses.append("scope IN (?, 'core')")
            params.append(target_scope)
        if page_types:
            placeholders = ",".join(["?"] * len(page_types))
            clauses.append(f"page_type IN ({placeholders})")
            params.extend(sorted(page_types))
        rows: list[sqlite3.Row] = []
        with self._connect() as conn:
            query = f"""
                SELECT * FROM wiki_pages
                WHERE {' AND '.join(clauses)}
                ORDER BY confidence DESC, updated_at DESC
                LIMIT 200
            """
            for row in conn.execute(query, params).fetchall():
                row_symbols = set(self._parse_json(row["symbols_json"], []))
                if symbols and not (row_symbols & symbols):
                    continue
                rows.append(row)
                if len(rows) >= limit:
                    break
        return rows

    def _extract_context_summary(self, page_id: str) -> str:
        page = self.read_page(page_id)
        content = str(page.get("content") or "")
        if "## Next Context Pack Summary" in content:
            summary = content.split("## Next Context Pack Summary", 1)[1].strip()
            summary = summary.split("\n## ", 1)[0].strip()
        else:
            summary = content[:1000].strip()
        title = content.split("\n", 1)[0].replace("#", "").strip() or page_id
        return f"### {page_id} — {title}\n{summary}"
```

```python
    def lint(self, *, scope: str = "") -> dict[str, Any]:
        self.initialize()
        clean_scope = str(scope or "").strip().lower()
        with self._connect() as conn:
            rows = conn.execute(
                """
                SELECT * FROM wiki_pages
                WHERE status = 'active' AND (? = '' OR scope = ?)
                ORDER BY updated_at DESC
                """,
                (clean_scope, clean_scope),
            ).fetchall()
            conn.execute("UPDATE wiki_lint_findings SET status = 'resolved', resolved_at = ? WHERE status = 'open'", (_utc_now_iso(),))
            findings: list[dict[str, Any]] = []
            for row in rows:
                page_id = str(row["page_id"])
                page = self.read_page(page_id)
                content = str(page.get("content") or "")
                source_refs = self._parse_json(row["source_refs_json"], [])
                if not source_refs:
                    findings.append(self._lint_finding(page_id, "warn", "missing_sources", "Page has no source refs."))

                if row["scope"] == "kis" and re.search(r"\\b[A-Z]{2,20}USDT\\b", content):

                    findings.append(self._lint_finding(page_id, "warn", "scope_leakage", "Binance page contains Korean equity code."))
            for finding in findings:
                conn.execute(
                    """
                    INSERT OR REPLACE INTO wiki_lint_findings (
                        finding_id, page_id, severity, finding_type, message,
                        evidence_json, status, created_at, resolved_at
                    ) VALUES (?, ?, ?, ?, ?, ?, 'open', ?, '')

                        finding["page_id"],
                        finding["severity"],
                        finding["finding_type"],
                        finding["message"],
                        _json_dumps(finding.get("evidence") or {}),
```

```python
from __future__ import annotations

import json
import logging
import time
from datetime import datetime, timezone
from pathlib import Path
from typing import Any

from tradecraft.config import settings
from tradecraft.services.jue_wiki import JueWikiConfig, JueWikiService

logger = logging.getLogger(__name__)


def _utc_now_iso() -> str:
    return datetime.now(timezone.utc).isoformat()


def _write_state(path: Path, payload: dict[str, Any]) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(payload, ensure_ascii=False, indent=2), encoding="utf-8")


def run_once(*, service: JueWikiService, state_path: Path) -> dict[str, Any]:
    started_at = _utc_now_iso()
    rebuild = service.rebuild(scope="all", force=False)
    lint = service.lint(scope="")
    result = {
        "status": "ok" if rebuild.get("status") == "ok" else "error",
        "started_at": started_at,
        "finished_at": _utc_now_iso(),
        "rebuild": rebuild,
        "lint": lint,
    }
    _write_state(state_path, result)
    return result


def build_service() -> JueWikiService:
    return JueWikiService(
        JueWikiConfig(
            root_path=Path(settings.jue_wiki_root_path),
            db_path=Path(settings.jue_wiki_db_path),
            context_max_chars=settings.jue_wiki_context_max_chars,
            page_max_chars=settings.jue_wiki_page_max_chars,
            context_page_limit=settings.jue_wiki_context_page_limit,
            kis_blocks_db_path=Path(settings.kis_block_trader_db_path),
            binance_blocks_db_path=Path(settings.binance_block_trader_db_path),
            investment_memory_db_path=Path(settings.investment_memory_db_path),
        )
    )


def run() -> None:
    logging.basicConfig(level=logging.INFO)
    service = build_service()
    state_path = Path(".runtime/jue_wiki_runner.json")
    interval = max(int(settings.jue_wiki_runner_interval_sec), 300)
    while True:
        try:
            result = run_once(service=service, state_path=state_path)
            logger.info("jue wiki cycle status=%s updated=%s", result["status"], result["rebuild"].get("updated_count"))
        except Exception as exc:
            logger.exception("jue wiki cycle failed: %s", exc)
            _write_state(
                state_path,
                {"status": "error", "error_message": str(exc), "finished_at": _utc_now_iso()},
            )
        time.sleep(interval)
```

## Risk Controls

1. Wiki pages cannot place orders.
2. Wiki context cannot override kill switch, cash limits, quantity limits, leverage limits, precision filters, or duplicate-order guards.
3. Wiki pages must include source references when compiled from source rows.
4. KIS pages and Binance pages must not leak into each other unless explicitly stored under `core`.
5. If wiki context errors, managers must continue with existing memory context and include `jue_wiki.status=error`.
6. If wiki context exceeds budget, trim wiki page content but preserve page IDs and source refs.
7. If RAG or ledger schemas differ in production DBs, rebuild should skip that source and record a lint/run warning instead of crashing a trading runner.

---

## Rollout Strategy

1. Land Tasks 1-6 with wiki disabled from manager prompts if needed.
2. Land Task 7 and expose wiki inside memory context.
3. Land Task 8 with a feature flag and start KIS/Binance prompt injection at small `jue_wiki_context_max_chars=12000`.
4. After one trading day, raise `jue_wiki_context_max_chars` to `24000` if LLM error rate drops or stays stable.
5. After one week, compare LLM usage:
   - `llm_prompt_payload_large` count before/after.
   - KIS manager success rate before/after.
   - Binance manager success rate before/after.
   - Average input chars by component.
6. Only then reduce raw memory/RAG prompt share.
